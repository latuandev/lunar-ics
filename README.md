## Note for GIT

- Please help apply GitFlow for this repository: <https://danielkummer.github.io/git-flow-cheatsheet>
- Name for implementing features: `feature/xxx-yyy`
- Example: `feature/implement-login-ui`
- Name for fixing bugs: `bugfix/xxx-yyy`
- Example: `bugfix/wrong-message-when-login`
- When creating a title for a pull request or a commit message, ensure the title is meaningful, capitalized, and avoids special characters.
- Example: `Implement the authentication feature`
